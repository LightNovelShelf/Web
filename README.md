# 轻书架 (light_novel_shelf)

A PWA-focused online novel reading project built with Quasar (@quasar/app-vite v3).

## Install dependencies

```bash
pnpm install
```

## Start development

```bash
pnpm dev
```

## Lint (oxlint)

```bash
pnpm lint        # oxlint --fix
pnpm lint:check  # oxlint, CI friendly
```

## Format (oxfmt)

```bash
pnpm format        # oxfmt, rewrites files
pnpm format:check  # oxfmt --check, CI friendly
```

## Type check

```bash
pnpm typecheck
```

## Build

```bash
pnpm build
```

## Build PWA

```bash
pnpm build:pwa
```

## Configuration

See the Quasar config documentation for customization details.
